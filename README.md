# AMAN.C — اختبار الترابط

هذه نسخة اختبارية مستقلة للتحقق من نشر صفحات GitHub Pages وترابط واجهة العميل مع واجهة الإدارة.

## الروابط
- الصفحة الرئيسية: https://aaaaubad-byte.github.io/AMAN.C/
- واجهة العميل: https://aaaaubad-byte.github.io/AMAN.C/client/
- واجهة الإدارة: https://aaaaubad-byte.github.io/AMAN.C/admin/

## طريقة الاختبار
1. افتح الصفحة الرئيسية.
2. افتح واجهة العميل وسجّل اسمًا ورقمًا وهميين.
3. افتح واجهة الإدارة في المتصفح نفسه وعلى النطاق نفسه.
4. تحقق من ظهور السجل. استخدم زر التحديث إذا لزم.
5. يمكن حذف سجلات الاختبار من زر الحذف في واجهة الإدارة.

## حدود الاختبار
- التخزين يتم في localStorage داخل المتصفح الحالي فقط.
- لا توجد قاعدة بيانات أو مصادقة أو صلاحيات حقيقية.
- لا تتزامن البيانات بين أجهزة أو متصفحات مختلفة.
- لا تدخل معلومات شخصية أو أرقامًا حقيقية.

## النشر والتحقق
يعمل GitHub Actions على فحص وجود الملفات والمسارات وصحة صياغة JavaScript قبل نشر محتويات المستودع إلى GitHub Pages.
