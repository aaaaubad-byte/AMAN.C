# AMAN.C — بناء المنتج الحقيقي

هذا المستودع هو التطبيق الأساسي لمشروع **أمان | حماية وضمان**. انتهت مرحلة اختبار الترابط السابقة، ويجري الآن بناء واجهات المنتج الفعلية وتجهيزها للربط بالخدمات الخلفية.

## واجهات التطبيق
- العميل: `/client/`
- الإدارة: `/admin/`

## المراجع المعتمدة
- مرجع AMAN.Y الوظيفي في الفرع `feature/aman-simplified-v2` مرجع للقواعد والتدفقات فقط، وليس مصدرًا لنسخ الواجهات أو الكود.
- الصورة المرجعية المرسلة من المستخدم هي مرجع الهوية البصرية: خلفية فاتحة، أسطح رمادية هادئة، كحلي للعناصر الأساسية، أخضر لحالات النجاح والنشاط، بطاقات مستديرة وأيقونات خطية.

## قواعد المنتج
- أمان خدمة حماية وضمان لأرقام الاتصالات من الفقدان بسبب عدم التجديد؛ ليست بنكًا أو محفظة أو خدمة تحويل أموال.
- لا تُفعّل الحماية بمجرد إدخال رقم أو تقديم طلب؛ يبدأ أثر الحماية بعد اعتماد الإدارة وفق دورة العمل المعتمدة.
- لا نقاط أو محفظة نقاط أو اشتراكات مستقلة.
- لا تُخترع شركات أو بادئات أو أسعار أو باقات أو تعليمات دفع.
- لا تُعرض بيانات عميل آخر عند الاستعلام عن رقم محمي لديه.
- التواريخ التشغيلية تعتمد توقيت صنعاء `Asia/Aden`.

## الحالة التقنية الحالية
- يجري تنفيذ بنية الواجهات والتنقل وحالات العرض.
- لم يتم بعد اختيار أو ربط قاعدة بيانات أو خدمة مصادقة أو واجهة دفع.
- لا تُستخدم بيانات اختبار `localStorage` كمصدر بيانات للمنتج.
- أي شاشة لم تُربط بالخادم تعرض حالة صريحة ولا توهم المستخدم بأن العملية تمت.
- لا توجد حاليًا عمليات دفع أو تحقق اتصالات أو اعتماد طلبات حقيقية من الواجهة.

## فحص المشروع محليًا
يتطلب فحص الملفات Node.js:
```bash
node scripts/validate.mjs
```

## النشر
ملف GitHub Actions الحالي ينشر فرع `main` إلى GitHub Pages. أعمال التطوير الجارية على فرع مستقل ولا تُنشر على الموقع العام قبل مراجعتها واعتماد نقلها إلى `main`.
