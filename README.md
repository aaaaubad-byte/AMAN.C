# AMAN.C — تأسيس المعاينة

مشروع واجهات هاتفية تدريجي لنظام أمان.

## الدفعة الأولى: اختبار الترابط المحلي
- `/client/`: تسجيل عميل تجريبي بالاسم ورقم الهاتف.
- `/admin/`: عرض سجلات العملاء التجريبية.
- `/shared/storage.js`: مخزن محلي مشترك بين الواجهتين على النطاق والمتصفح نفسيهما.
- `/styles/app.css`: تنسيق موحد يبدأ من تجربة الهاتف.

## حدود الاختبار
هذه البيانات محفوظة في Local Storage للمتصفح، وليست قاعدة بيانات. لا توجد مصادقة أو صلاحيات أو مزامنة بين الأجهزة. لا تدخل بيانات حقيقية أو كلمات مرور. احذف بيانات الاختبار قبل الانتقال إلى بيانات فعلية.

## النشر
يتم النشر إلى GitHub Pages عبر GitHub Actions عند كل دفع إلى الفرع main، بعد تفعيل Pages باستخدام GitHub Actions من إعدادات المستودع.
