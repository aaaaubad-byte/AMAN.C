# المعاينة المحلية لمحاكاة AMAN.C

هذه محاكاة محلية لاختبار واجهتي العميل والإدارة. لا تتصل بقاعدة بيانات أو خادم أو شركة اتصالات أو بوابة دفع، ولا يجوز إدخال بيانات حقيقية.

## التشغيل
من جذر المستودع شغّل:

```bash
node scripts/local-preview.mjs
```

ثم افتح:
- العميل: http://127.0.0.1:8080/client/
- الإدارة: http://127.0.0.1:8080/admin/

خادم المعاينة يحقن علامة المحاكاة ويحمل محوّل المحاكاة أثناء تقديم الصفحات محليًا فقط. لا تستخدم `?demo=1`؛ لم يعد هذا هو أسلوب التشغيل المعتمد.

## المعاينة بلا محاكاة
أوقف الخادم ثم شغّل:

```bash
node scripts/local-preview.mjs --no-simulation
```

افتح الرابطين نفسيهما. ينبغي أن تظهر رسالة «الخدمة غير مهيأة»، وألا تنفّذ الواجهات عمليات وهمية أو تحفظ بيانات محاكاة.

## البيانات والأمان
- المحاكاة محلية وتبدأ بحالة فارغة، مع حساب مدير المحاكاة اللازم لتسجيل الدخول.
- التخزين محلي ومعزول تحت مفتاح خاص بالمحاكاة؛ لا تستخدم بيانات عملاء أو أرقامًا أو مراجع دفع حقيقية.
- كلمات المرور في المحاكاة ليست آمنة، وهذه ليست مصادقة إنتاجية.
- لا ترفع المحاكاة إلى موقع عام ولا تفعّلها على نطاق إنتاج.
- المشروع غير مربوط بقاعدة بيانات تشغيلية. نجاح المعاينة أو الاختبارات لا يعني جاهزية المنتج للإنتاج.

## التحقق
```bash
node scripts/validate.mjs
node --test tests/*.test.js tests/*.test.mjs
```

لا تُعتبر الاختبارات ناجحة إلا بعد تشغيلها ومراجعة نتيجتها الفعلية.
