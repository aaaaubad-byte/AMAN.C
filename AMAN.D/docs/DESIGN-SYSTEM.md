# نظام التصميم

## الاتجاه واللغة

- الواجهات عربية، باتجاه RTL، ومصممة أولًا لشاشات الهاتف.
- تستخدم البنية صفحات مستقلة للعميل والإدارة، مع رأس ومحتوى قابل للتمرير وتنقل سفلي عند الحاجة.
- يجب أن تبقى حالات الفراغ والتحميل والخطأ ضمن تخطيط الشاشة بدل اختفاء الهيكل أو نقل النتيجة إلى موضع غير متوقع.

## الألوان والرموز

- اللون الفيروزي المعتمد هو `#078F87` ويُعرّف عبر الرمز `--turquoise`.
- تُدار الألوان الفاتحة والداكنة من رموز CSS في `styles/base.css`، وتُستكمل التفاصيل البصرية في `styles/visual.css`.
- لا تُضاف قيم لونية متعارضة داخل مكونات منفردة إذا كان لها رمز مركزي.
- تُستخدم درجات الحبر والخلفية والحواف والحالات من رموز التصميم بدل إعادة اختراع لوحة ألوان لكل شاشة.

## السمة

يوفر `shared/theme.js` ثلاثة اختيارات:

- حسب الجهاز: الافتراضي، ويتبع إعداد النظام.
- فاتح.
- داكن.

يُحفظ تفضيل السمة ويُطبّق على عنصر الجذر، ولون شريط المتصفح، ومصدر الشعار المناسب. يتابع التطبيق تغيّر تفضيل النظام عندما يكون الاختيار «حسب الجهاز».

## الأيقونات

تُستخدم أيقونات SVG داخلية متسقة. يتولى `shared/ui-icons.js` معالجة بصمات الأيقونات والبطاقات المشتركة، وتبقى أيقونات الفلاتر الخطية متوافقة مع بصمات الاستبدال المعتمدة.

## الأنماط

| الملف | الوظيفة |
|---|---|
| `styles/base.css` | القواعد الأساسية والرموز والتخطيط |
| `styles/visual.css` | الطبقة البصرية والأيقونات والبطاقات والتفاصيل |
| `styles/admin-login.css` | تنسيق شاشة دخول الإدارة |

يُحمّل `theme.js` الطبقة البصرية بعد القواعد الأساسية حتى لا تتغير أولوية الطبقات المعتمدة.

## أصول الهوية

الأصول الثنائية للشعار وأيقونات PWA مؤجلة حاليًا تحت P-01؛ يجب توفير ملفات PNG الأصلية بالأسماء المحددة في الشجرة قبل اعتماد اكتمال الهوية أو نجاح تحقق الأيقونات. لا تستبدل PNG بـSVG دون قرار معتمد.
