# مواصفات واجهة العميل

## بوابة المصادقة

الشاشات العامة دون جلسة هي التمهيد وتسجيل الدخول وإنشاء الحساب فقط. أي محاولة لفتح شاشة داخلية دون جلسة تُحوّل إلى الدخول. إذا انتهت الجلسة أثناء الاستخدام، يعاد العميل إلى شاشة الدخول برسالة واضحة.

## الشاشات

| الشاشة | الوظيفة |
|---|---|
| boot | استعادة الجلسة وتحديد وجهة البدء |
| login | تسجيل الدخول |
| signup | إنشاء حساب |
| home | الصفحة الرئيسية |
| numbers | أرقام العميل |
| operations | سجل العمليات |
| operation-detail | تفاصيل عملية |
| protection | كتالوج الحماية واختيار العملية |
| review | مراجعة الطلب قبل الإرسال |
| result | نتيجة العملية المؤكدة أو غير المؤكدة |
| account | بيانات الحساب وتغيير كلمة المرور |
| notifications | إشعارات العميل |
| number-alerts | تنبيهات الأرقام |
| report | إرسال بلاغ |
| aman-service | شاشة خدمة أمان |

## العمليات

تستدعي الواجهة الخدمات المشتركة للبحث عن رقم، وعرض أرقام العميل وعملياته، وتحميل كتالوج الحماية، وإرسال طلب حماية، وتحديث الملف الشخصي، وتغيير كلمة المرور، وقراءة الإشعارات والتنبيهات، وإرسال بلاغ.

لا تُعرض عملية على أنها مكتملة قبل أن تعيد الخدمة `success: true`. عند انقطاع الشبكة أثناء عملية مغيّرة، تعرض الواجهة أن النتيجة لم تتأكد بدل إعادة الإرسال تلقائيًا.

## عرض الحالات

- تُفصل حالة الرقم عن حالة الطلب.
- الطلب المعلق لا يُعامل كحماية معتمدة.
- تُعرض تفاصيل الطلب أو العملية من استجابة الخدمة، ولا تُنشأ بيانات افتراضية لإكمال الشاشة.
- رسائل الأخطاء عربية، وتوضح ما إذا كانت العملية لم تنفذ أو لم يتم تأكيد نتيجتها.

## الحساب والخصوصية

تُدار الجلسة عبر محوّل Supabase. لا تتعامل شاشة العميل مباشرة مع localStorage أو sessionStorage. عمليات تحديث الحساب وكلمة المرور تمر عبر الخدمة ولا تتجاوز التحقق الذي يفرضه الخادم.
