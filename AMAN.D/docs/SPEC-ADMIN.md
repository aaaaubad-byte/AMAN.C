# مواصفات واجهة الإدارة

## الدخول

تتطلب واجهة الإدارة بريدًا إلكترونيًا وكلمة مرور. خيار «تذكرني» يمرر إلى المحوّل، ويُرفض الحساب الذي لا يؤكد الخادم أنه مدير. لا يوجد مسار لإنشاء حساب إداري من شاشة الدخول.

## لوحة الإدارة

تعرض لوحة الإدارة ملخصًا للطلبات قيد المراجعة، والأرقام المحمية، والبلاغات المفتوحة، ومهام السداد، والعملاء، والإيرادات المعتمدة. وتوفر اختصارات إلى الأقسام التشغيلية.

## الأقسام

| القسم | الوظيفة |
|---|---|
| الطلبات | بحث وتصفية حسب الحالة ونوع العملية والشركة، ثم تفاصيل ومراجعة الطلب |
| الأرقام | البحث حسب الرقم أو الشركة والحالة، وعرض التفاصيل والسجلات للقراءة فقط |
| العملاء | البحث والتصفية، تفاصيل الحساب والأرقام والطلبات، وتعطيل/إعادة تفعيل الحساب |
| مهام السداد | عرض المخططة والمستحقة والمنفذة، تنفيذ المهمة أو إعادة جدولتها بعد معاينة |
| نافذة الظهور والمتابعة | متابعة المهام داخل نافذة الشركة وخارجها |
| التقارير | الإيرادات المعتمدة حسب الفترة والشركة والعملية والباقة ووسيلة الدفع |
| البلاغات | تفاصيل البلاغ وتسجيل قرار المعالجة وسببه |
| الإشعارات | عرض الإشعارات وإنشاء إشعار يدوي لمستلم محدد أو للعملاء |
| تنبيهات الأرقام | إنشاء تنبيه يدوي للعميل المرتبط بالرقم |
| الشركات والإعدادات | الاسم والبادئات وأطوال الأرقام والفاصل الدوري ونافذة الظهور وإعدادات التنشيط |
| الباقات | إنشاء وتعديل باقات الشركة ونوع العملية والمدة والسعر |
| وسائل الدفع | الاسم والتعليمات ورقم الحساب واشتراط مرجع الدفع |
| المحتوى الثابت | الشروط والخصوصية والتواصل والمساعدة |
| سجل التدقيق | تصفية السجلات وعرض تفاصيل الإجراء |
| الحساب الإداري | بيانات المدير والسمة وتسجيل الخروج |

## مراجعة الطلب

- تبدأ القائمة بحالة «قيد المراجعة».
- تعرض عوامل التصفية البحث، وحالة الطلب، ونوع العملية، والشركة.
- تحتوي التفاصيل على بيانات الطلب والعميل وحالة الرقم والتنبيهات.
- الاعتماد يتطلب معاينة أثر موثوقة من الخادم قبل التأكيد.
- الرفض يتطلب اختيار سبب معتمد؛ ويقبل توضيحًا إضافيًا ضمن الحد الذي يفرضه الخادم.
- بعد القرار تُحدّث التفاصيل والقائمة، ولا تُعرض رسالة نجاح قبل تأكيد الخدمة.

## الأمان

حارس الواجهة وسيلة عرض فقط. صلاحيات كل RPC وعزل البيانات يتحقق منهما الخادم وقاعدة البيانات. شاشة تفاصيل الرقم لا تقدم أزرار اشتراك أو تمديد أو تنشيط.
