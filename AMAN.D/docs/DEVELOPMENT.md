# التطوير والتحقق

## المتطلبات

- Node.js 22 أو أحدث.
- لا يتطلب تشغيل التطبيق تثبيت حزمة محاكاة أو بيانات تجريبية.
- تعتمد الواجهات على مكتبة Supabase JS المثبت رابطها في صفحات HTML، وعلى طبقة الخدمات الموجودة داخل AMAN.D.

## الأوامر

بعد إعداد ملفات الجذر:

- `npm run validate`: تحقق بنيوي من الملفات والمسارات وصياغة JavaScript والاستقلال ومراجع PWA.
- `npm test`: تشغيل اختبارات Node الموجودة في tests.
- `npm run build`: إنشاء مجلد dist بعد نجاح التحقق.
- `npm run serve`: خدمة ملفات dist محليًا على 127.0.0.1.

## سير العمل

1. عدّل ملفات AMAN.D فقط.
2. حافظ على عقود `AMANClientServices` و`AMANAdminServices`.
3. لا تنشئ نتيجة ناجحة إذا فشلت الخدمة أو لم يتأكد الخادم من العملية.
4. نفّذ تحققًا موضعيًا ضروريًا أثناء الكتابة.
5. بعد اكتمال الكتابة وحسم المسائل المؤجلة، تُنفذ الاختبارات الشاملة في مرحلة مستقلة.

## الاختبارات

تغطي ملفات tests محوّل Supabase، بوابة مصادقة العميل، الاستقلال، PWA، السمة ورموز التصميم. كُتبت ملفات الاختبارات في مرحلة الكتابة الحالية ولم تُشغّل بعد. الاختبارات التي تتطلب متصفحًا أو قاعدة تطوير مستقلة لا تُعد ناجحة لمجرد وجود ملفاتها.

اختبارات SQL وقواعد المهام التي تتطلب بيئة مستقلة تبقى مؤجلة وفق Q3، ولا تُشغّل على الإنتاج.

## البناء والتشغيل

- ينشئ `scripts/build.mjs` مجلد `dist/` من ملفات التشغيل فقط ويختم `__BUILD_ID__` في عاملي الخدمة.
- يخدم `scripts/serve.mjs` النسخة المبنية فقط، ويستمع على 127.0.0.1.
- لا يوجد وضع معاينة يحقن محاكاة. لا تضف محولًا وهميًا أو بيانات افتراضية إلى ملفات التشغيل.
