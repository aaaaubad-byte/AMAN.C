# AMAN.D | أمان

إعادة بناء مستقلة لتطبيق أمان، تضم واجهة العميل وواجهة الإدارة وطبقة خدمات مشتركة تتصل بمشروع Supabase الحالي نفسه.

## التشغيل

يتطلب Node.js 22 أو أحدث.

```sh
npm run validate
npm test
npm run build
npm run serve
```

يخدم الخادم المحلي محتويات `dist/` بعد نجاح البناء. يبدأ مسار الجذر بفتح تطبيق العميل، وتتوفر واجهة الإدارة في `/admin/`.

## البنية

- `client/`: تطبيق العميل.
- `admin/`: تطبيق الإدارة.
- `shared/`: عقود الخدمات ومحوّل Supabase والسمة والأيقونات.
- `styles/`: نظام الأنماط.
- `assets/`: أصول الهوية.
- `supabase/migrations/`: نسخ مرجعية حرفية من ترحيلات قاعدة البيانات الحالية.
- `scripts/`: التحقق والبناء والخادم الثابت.
- `tests/`: اختبارات التطبيق.
- `docs/`: مواصفات التنفيذ والتشغيل والأمان.

## قاعدة البيانات

يستخدم التطبيق قاعدة Supabase الحالية الخاصة بـ AMAN.C. لا ينشئ قاعدة جديدة. ملفات الترحيل نسخ من تاريخ المخطط الحالي، ولا تُطبّق على قاعدة الإنتاج ضمن مرحلة إعادة البناء.

## الاستقلال

لا يعتمد تشغيل أو بناء AMAN.D على ملفات AMAN.C أو AMAN.B. لا توجد محاكاة أو بيانات وهمية في مسار التشغيل. عند عدم تهيئة الخدمة، تعرض الواجهات حالة عدم التهيئة ولا تصطنع نجاحًا.

## ملاحظات قبل التسليم

- أصول PNG للشعار وأيقونات PWA ما زالت مؤجلة وفق P-01؛ لا يُعتمد اكتمال الهوية أو نجاح تحقق الأيقونات قبل توفيرها.
- وجود ملفات الاختبارات لا يعني أنها شُغّلت أو نجحت.
- `deploy/pages.yml` قالب يدوي غير مفعّل؛ لا يُنشر التطبيق قبل الاختبارات والمراجعة والموافقة.
