## المكونات كما تظهر في المرجع
- **الأزرار:** أساسي أخضر، ثانوي كحلي، تأكيد كحلي، نصي بحدود، هادئ بخلفية رمادية فاتحة، إلغاء بحدود.
- **حقول الإدخال:** خلفية بيضاء وحدود ناعمة وزوايا مستديرة، مع أيقونة عند الطرف (بحث، هاتف، شركة)، ورمز الدولة +967 لرقم الهاتف.
- **الشارات والحالات:** نشط، معتمد، مرفوض، قيد المراجعة، غير مشترك، منتهي، محمي.
- **التنقل السفلي:** الرئيسية، العملاء، الاشتراكات، المهام، المزيد؛ العنصر النشط بالأخضر.
- **عناصر إدارية:** سجل التدقيق، الشركات والإعدادات، وسائل الدفع، باقات الحماية، التقارير والإيرادات.

## قاعدة العمل
أي شاشة جديدة أو معدّلة تُطابق هذا المرجع في الألوان والخط والأزرار والحقول والتباعد.
